**Cadio** помогает найти совместную тренировку или клуб рядом, записаться, прийти — и вернуться.
Приложение нужно, чтобы быстрее выйти из него и встретить людей в своём городе.

## Как это работает

<p align="center">
  <img src="https://raw.githubusercontent.com/Cadio-Team/.github/main/profile/assets/steps.png" alt="Четыре шага: нашёл, записался, пришёл, вернулся" width="100%">
</p>

Открываешь Cadio и видишь, что происходит рядом сегодня: кто тренируется, в каком темпе, где встречаются и сколько мест осталось. Записываешься, приходишь, знакомишься. В следующий раз идёшь уже к своим.

## Организаторам

<p align="center">
  <img src="https://raw.githubusercontent.com/Cadio-Team/.github/main/profile/assets/organizers.png" alt="Собирай людей. Не таблицы. Пример карточки события для организатора" width="100%">
</p>

- Страница клуба с расписанием: её видят не только в твоём чате.
- Запись без перекличек: список участников и свободные места всегда под рукой.
- Регулярные тренировки создаются один раз.
- Отметка посещаемости: видно, кто приходит снова.
- Чат клуба остаётся там, где он есть. Cadio его не заменяет.

## Чем Cadio не является

| | |
| --- | --- |
| **Не трекер** | Мы не про километры и рекорды, а про людей и встречи. |
| **Не афиша** | Важно не разовое событие, а привычка приходить. |
| **Не соцсеть** | Онлайн нужен только затем, чтобы проще встретиться офлайн. |

## Виды спорта

Начинаем с бега в Санкт-Петербурге. Дальше — лыжи и коньки, велосипед, плавание и другие виды спорта, которыми занимаются вместе.

## Из чего состоит продукт

| Часть | Что это | На чём |
| --- | --- | --- |
| Приложение | iOS и Android, основной способ пользоваться Cadio | Flutter |
| Сайт | Страницы событий и клубов, кабинет организатора | Next.js |
| Сервер | Единый API для приложения и сайта | Go, PostgreSQL |
